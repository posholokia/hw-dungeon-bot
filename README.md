# Бот для автопрохождения подземелья

Команда запуска на Windows с логами:
## Запуск бота
### Команды
1. Из командной строки
`.\hw-dungeon-bot.exe`

2. Из PowerShell
```
cmd /c ".\hw-dungeon-bot.exe"
```
### Аргументы
--level -l [ARGUMENT]: Текущий уровень
--complete -c [ARGUMENT]: Сколько уровней пройти
--target -t [ARGUMENT]: До какого уровня дойти
--debug: Включить режим отладки
